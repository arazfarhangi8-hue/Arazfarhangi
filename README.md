# مهر فرازان 🎓

پایه اولیه پلتفرم مهر فرازان؛ سامانه‌ای برای کلاس و جلسه آنلاین با مدل درآمدی ساده:

- یک اشتراک پولی اقتصادی برای معلم
- دانش‌آموز برای ورود به جلسه دعوت‌شده اشتراک جداگانه نمی‌خرد
- تخته سفید با امکان قفل/بازکردن توسط معلم
- رابط کاربری فارسی و واکنش‌گرا
- جایگاه آماده برای تماس صوتی/تصویری، ضبط جلسه و اشتراک صفحه
- حساب کاربری و پنل مدیریتی در نقشه راه

## وضعیت فعلی
این نسخه یک **نمونه اولیه سمت کاربر** است. حساب کاربری، پرداخت واقعی و تماس ویدئویی هنوز به سرویس‌های سمت سرور متصل نشده‌اند. برای نسخه عملیاتی باید احراز هویت امن، پایگاه داده، WebRTC/سرور اتاق جلسه و درگاه پرداخت اضافه شوند.
